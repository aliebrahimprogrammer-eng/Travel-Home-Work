# Travel Explorer API

A Spring Boot REST API for exploring travel destinations.

## Endpoints

GET /api/travel
GET /api/destinations
GET /api/destinations/{id}
GET /api/destinations/search?name=Tokyo
GET /api/destinations/filter?category=Beach
POST /api/destinations
PUT /api/destinations/{id}
DELETE /api/destinations/{id}
GET /api/destinations/stats
GET /api/destinations/random
